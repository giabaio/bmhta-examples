# Chapter: Missing data and structural values in HTA

## Overview

This chapter addresses two pervasive complications in HTA trial data: missing outcomes and structural values (e.g. a spike of QALYs at exactly 1, or zero costs). It covers the theory of missingness mechanisms (MCAR, MAR, MNAR), demonstrates bias under each via simulation, introduces multiple imputation as a "Bayesian in spirit" method and shows how a full Bayesian framework handles missingness more naturally. The main applied example is the MenSS pilot RCT, where three competing joint models for the bivariate (e, c) outcome are compared: Normal-Normal MCF, Beta-Gamma MCF (rescaled), and a Beta-Gamma hurdle model that explicitly accommodates the structural-ones spike.

## Code structure

### Complete case analysis

A short demonstration showing that `lm()` silently performs CCA when data contain `NA`s — deleting 20 observations and reporting the reduction in the message. Under MCAR, the estimates remain approximately unbiased.

### Simulation study — bias under different mechanisms

Four scenarios are run with S=1000 repetitions each, all using the same MoA (y = 0.5 + 1.5*x + Normal(0,1), n=2000):

- **MNAR**: `pi = ilogit(-0.5 + 0.35*x + 0.83*y)` — the strong coefficient on y induces substantial bias in the CCA estimates for beta0 and beta1.
- **MAR**: `pi = ilogit(0.17 + 0.35*x + 0*y)` — x explains all missingness, so CCA estimates remain unbiased. The delta0 intercept is adjusted to maintain a similar average missing-data rate.
- **MCAR**: `pi = ilogit(0.5 + 0*x + 0*y)` — completely random; CCA unbiased and slightly more precise than MAR.
- **No missing**: `pi = rep(0, 2000)` — baseline reference for achievable precision.

`bmhe::ilogit()` computes the inverse logit. The estimates under each scenario are summarised with `bmhe::stats()`.

### Multiple imputation

Illustrates the mechanics of MI on simulated data with a single covariate. A "population" of N=1000 is constructed and a sample is drawn with a 20% MCAR dropout. The predictive model `lm(y ~ x4)` is fitted on the observed data; R=5 imputed values per missing observation are drawn from Normal(mu_hat, sigma_hat) using `sigma.hat()` from the `arm` package. Three plots are produced: (a) observed data with `?` markers for missing individuals; (b) fitted regression line; (c) the five imputed datasets overlaid.

### MenSS trial — descriptive analysis

Loads `data_MenSS.rds` and builds a single tibble with QALYs, costs and treatment indicator. Two histograms (one per outcome) show the strong spike at QALY=1 in both arms and the right-skewed cost distributions.

### MenSS trial — three model comparisons

Pre-computed JAGS results are loaded from `MenSS_JAGS_models.rds`. Each object `objs$cp1/cp2/cp3` contains a tibble of posterior predictive summaries per individual (mean, SD, 2.5%, 97.5%), missingness indicator (`shp`) and treatment arm.

The three models are:

**Normal-Normal MCF** (`objs$cp1`). Standard MCF with Normal likelihood for both e and c, controlling for baseline utility. Unconstrained: posterior predictions for missing QALYs can exceed 1, inflating estimated average effectiveness.

**Beta-Gamma MCF rescaled** (`objs$cp2`). Replaces the Normal with a Beta for QALYs and Gamma (or log-Normal) for costs. Because the Beta requires strict (0,1) support, all QALYs are shifted by eps=0.01 to remove the spike at 1. This is correctly bounded but introduces slight downward bias and ignores the structural-ones subgroup.

**Beta-Gamma MCF with hurdle** (`objs$cp3`). A two-component model: a Bernoulli logistic regression identifies individuals likely to have QALY=1 (structural ones), who are assigned the fixed value of 1; the remainder are modelled with Beta. The population average effectiveness is a weighted mixture: `mu_e[t] = (1 - gamma_bar[t]) * mu_e_lt1[t] + gamma_bar[t]`. This correctly captures the multimodal structure of the data.

Two versions of the comparison plot are produced: a full three-model faceted figure and a cleaner two-model overlay (Beta-Gamma variants only) for the main publication figure.
